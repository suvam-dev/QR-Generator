# QR Code Generator

A sleek, fast, and modern QR Code generator built with Next.js, React, and Tailwind CSS. Generates instant, high-resolution QR codes from any URL or text with one-click download.

---

## Features

- **Instant Generation**: Generates QR codes in real-time as you type.
- **High Resolution**: 1024px output with High (`H`) error correction for crisp display and scanning.
- **One-Click Download**: Download your generated QR code as a PNG directly to your device.
- **Modern UI**: Dark glassmorphic interface with smooth animations.

---

## Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Libraries**: `qrcode`, `framer-motion`, `lucide-react`
- **Package Manager**: pnpm

---

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/your-username/qr-generator.git
cd qr-generator
```

### 2. Install dependencies

```bash
pnpm install
```

### 3. Run the development server

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
